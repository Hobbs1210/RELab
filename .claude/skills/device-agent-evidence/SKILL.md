# Device Agent Evidence

Use project-scoped evidence IDs to support claims. Retrieve prior findings from `research_search_agent_memory`, classify each new finding as observed, hypothesis, verified or refuted, and never manufacture certainty. Generate reports and bundles only from the selected project. Do not include raw firmware, secrets, PCAP payloads or credentials in public issues unless reviewed and authorized.

## Constraints

Research only owned or authorized hardware and networks. Document source material, hashes and reversible experiment steps. Follow `AGENTS.md`, `docs/RESEARCH_HUB.md` and `SECURITY.md`.
