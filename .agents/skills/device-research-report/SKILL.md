# Write evidence-first protocol research reports

## Workflow

Run scripts/generate-findings.py then connect each hypothesis to capture hash, observed API event, firmware offset, and reproduction. Mark unknowns and confidence. Never present simulated backend success as real device progress.

## Evidence & safety

Operate only on devices and networks you own or have permission to test. Persist relevant observations and reversible changes. Do not invent a device protocol or bypass TLS validation based on DNS alone.
